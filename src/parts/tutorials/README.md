# 教程部

负责教程列表和每一篇教程。

**每篇教程是一个独立单元**：`tutorials` 表里的一行（标题、简介、分类、难度、时长、标签、正文、草稿状态）加上它自己的历史版本（最近 30 次）。

- 新增、修改、删除一篇只动这一行，不需要重新构建或重启网站
- 每篇单独渲染、单独缓存；某一篇内容写坏了只影响它自己的页面
- 某一篇的数据损坏时，列表里只隐藏它，其他教程照常显示
- 账号中心「网站结构」里可以看到每个单元的状态、最近修改人和历史版本数

| 文件 | 作用 |
| --- | --- |
| `part.ts` | 教程部的配置：列表标题、分类（删除仍在使用的分类会被拒绝） |
| `store.ts` | 每篇教程的读写、草稿、改网址、删除、历史版本 |
| `render.ts` + `remark-callout.mjs` | Markdown 渲染、提示框写法 |
| `components/TutorialGrid.astro` | 首页的教程列表（筛选、搜索、新建） |
| `components/TutorialPage.astro` | 教程页（阅读 + 管理员编辑器） |
| `seed/` | 全新数据库第一次启动时导入的示例教程 |
